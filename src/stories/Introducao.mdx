# SmileSync

Catálogo da interface do frontend. Os textos e os dados vêm dos mocks em `src/mocks`. Alterações feitas nas stories de pacientes, agenda e financeiro ficam só na memória da aba.

## Como abrir

```bash
npm run storybook
```

O catálogo sobe em [http://localhost:6006](http://localhost:6006).

## O que está documentado

- **Fundamentos:** cores e tipografia usadas no Tailwind.
- **Componentes:** botão, logotipo, estado vazio e skeletons.
- **Telas:** landing, autenticação, painel, agenda, pacientes, financeiro, reativação e relatórios.

As telas internas usam o mesmo menu lateral do layout `(interno)`.
